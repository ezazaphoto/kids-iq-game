# 🧠 لعبة ذكاء الأطفال — Kids IQ Game

لعبة ذكاء عربية للأطفال (RTL) بأربع مستويات من السهل إلى الخبير، كل مستوى 10 أسئلة في الحساب والأنماط والمنطق والأشكال.

## ✨ المميزات
- **4 مستويات:** سهل 🌱 (4–6 سنوات)، متوسط 🌟 (7–9)، صعب 🚀 (10–12)، خبير 👑 (تحدي الأذكياء).
- **40 سؤالًا** مع شرح مبسط لكل إجابة.
- **لو الطفل جاوب غلط:** اللعبة توضح له الإجابة الصحيحة وتشرحها له **بالصوت** (نطق عربي عبر Web Speech API)، مع زر لإعادة سماع الشرح.
- **لو جاوب صح:** تشجيع صوتي ونقاط ونجوم.
- **شريط تقدم** وعدد نقاط وأفضل نتيجة محفوظة على الجهاز (localStorage).
- تعمل أوفلاين بالكامل — لا تحتاج إنترنت.

## ▶️ التشغيل على الكمبيوتر
افتح ملف `index.html` في أي متصفح حديث (Chrome / Edge / Firefox).

> ملحوظة: الصوت العربي يعتمد على أصوات النطق المثبتة على الجهاز/المتصفح. على أندرويد يعمل عبر محرك تحويل النص إلى كلام (TTS) الخاص بالنظام.

## 📱 تطبيق أندرويد (APK)
المشروع فيه غلاف أندرويد (WebView) في مجلد `android/` يعرض نفس اللعبة داخل تطبيق.

### طريقة الحصول على الـ APK (الأسهل — من GitHub Actions)
1. افتح صفحة المستودع على GitHub ← تبويب **Actions**.
2. اختر آخر تشغيل ناجح لـ **Build APK** ← من قسم **Artifacts** حمّل `kids-iq-game-apk`.
3. فك الضغط وثبّت ملف `app-debug.apk` على الموبايل (فعّل «التثبيت من مصادر غير معروفة» عند الطلب).

الـ APK يُبنى تلقائيًا عند كل Push على فرع `main` عبر ملف `.github/workflows/build-apk.yml`.

### البناء محليًا (للمطورين)
```bash
cp index.html android/app/src/main/assets/index.html
cd android
./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```
يتطلب JDK 17 وAndroid SDK (compileSdk 34 / minSdk 24).

## 🔧 التطوير
- لإضافة أسئلة جديدة: عدّل مصفوفة `QUESTIONS` في `index.html` (كل سؤال: نص، 4 اختيارات، رقم الإجابة الصحيحة، شرح مبسط، إيموجي).
- لإضافة مستوى جديد: أضف عنصرًا في مصفوفة `LEVELS` وأسئلته في `QUESTIONS`.
- ملف `index.html` هو المصدر الوحيد؛ مهمة البناء تنسخه تلقائيًا إلى أصول الأندرويد قبل التجميع.
